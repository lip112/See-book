# 개요

사용자들끼리 책의 한줄평 리뷰를 남기고 서로 책의 정보를 공유하는 어플, 책 뒤에 isbn 바코드를 인식하여 한 번에 책을 찾을 수 있고 즉시 댓글들을 확인하여 책의 정보를 얻을 수 있음
